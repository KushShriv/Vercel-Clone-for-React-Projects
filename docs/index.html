Build a React project on your machine.

A local service can build a supported public GitHub repository and preview its static output. GitHub Pages hosts this interface; it does not run builds.

Experimental software

The isolated worker and cross-browser connection require further validation. Docker is not a complete security boundary; use an isolated VM for untrusted projects. A local preview is not a public deployment.

Start locally

  1. Obtain the source or a reviewed release. Install Node.js 20 or newer and start Docker.
  2. Run ./start.sh from the extracted project folder. The terminal prints a dashboard address and a pairing token.
  3. Open the local mode below, paste the token, and explicitly confirm the repository before building. If your browser blocks Pages from reaching loopback, open the dashboard URL printed by the launcher instead.

What to expect

The initial convention is a root Vite/React project with a locked npm dependency tree and an exact vite build script. Dependencies are installed without lifecycle scripts. Builds consume CPU, disk and network. Stop the service with Ctrl-C; abrupt termination can leave Docker resources and temporary files that need manual cleanup.

Preview security restrictions block inline scripts and styles, forms and network requests. Some sites may not work in preview. No public hosting, cloud account setup or costs are included.

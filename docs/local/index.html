Before you build
Docker is not a complete security boundary. Use an isolated virtual machine for repositories you do not trust. Builds can use disk space, CPU and network bandwidth. A local preview is not a public deployment. Preview security restrictions block inline scripts and styles, forms, and network requests, so apps that depend on them may not work.
